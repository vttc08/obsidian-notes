Sort a file content by alphabetical order
```bash
sort file.txt
```
Sort file content without duplicates
```bash
sort -u file.txt
```
Sort file content randomly
```bash
sort -R file.txt
```
Sort numerically
```bash
sort -n file.txt
```
- without this option file will be sorted like 1 10 11 2... rather than 1 2 3 4...
